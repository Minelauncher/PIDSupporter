NativeRen.cs implements the SISO nx=nv=8, tanh, D22=0 specialization with polar
H parameterization. The reusable reverse-AD tape, explicit BPTT, Adam loop,
worker scheduling and game integration are C# implementations in this project.
No Python/JAX code runs or is required when using the packaged mod.

Mathematical parameterization is compared against the original implementation
using shared direct parameters. Initialization randomness differs, so training
trajectories and benchmark outcomes are not claimed identical.
